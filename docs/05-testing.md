# Тестирование

Проект проверяется на трёх уровнях: скриптами на схему и алгоритмы,
автоматическими тестами и ручным прогоном сценариев.

## 1. Проверка схемы и алгоритмов

Два скрипта на Python проверяют то, что дороже всего чинить после сдачи:
устройство базы данных и разметку PDF-документа. Они не требуют Android SDK
и запускаются на любой машине.

```bash
python3 tools/verify_schema.py      # 61 проверка
python3 tools/verify_pdf_layout.py  # 22 проверки
```

### tools/verify_schema.py

Поднимает базу SQLite в памяти, применяет `tools/schema.sql`, заполняет
тестовыми данными и проверяет:

| Блок | Что проверяется |
|------|-----------------|
| Структура | Три основные таблицы, промежуточная и виртуальная таблица поиска |
| Внешние ключи | Объявлены, включены, отклоняют ссылку на несуществующую категорию |
| Связь «один-ко-многим» | Количество записей в каждой категории |
| Связь «многие-ко-многим» | Теги записи, записи тега, запрет дубликата связи |
| Каскадное удаление | Удаление категории убирает её записи, удаление записи — связи с тегами |
| Полнотекстовый поиск | Поиск по слову, независимость от регистра, запрос из нескольких слов, обновление индекса при UPDATE и DELETE |
| Статистика | Общее число, частое настроение, распределение по категориям, записи за период |
| Поиск и фильтры | Три режима сортировки, поиск, три фильтра и их совместная работа |
| Серия дней | Алгоритм подсчёта дней подряд, включая границы «сегодня» и «вчера» |

Именно эта проверка нашла реальную ошибку: со стандартным токенизатором FTS4
запрос «парк» не находил запись «Парковка», потому что `simple` не приводит
к нижнему регистру кириллицу. Отсюда — `tokenize=unicode61` в схеме.

### tools/verify_pdf_layout.py

Алгоритмы переноса строк и разбиения на страницы из `PdfExporter`
повторены на Python и проверяются на инвариантах: ни одна строка не шире
листа, ни одно слово не потеряно, слово длиннее строки разрывается, записи
не выходят за нижний край страницы.

Проверить это глазами по коду нельзя — ошибка видна только в готовом
документе, а собрать его без устройства невозможно.

## 2. Автоматические тесты

### Unit-тесты (23 тестов)

Запускаются на JVM, устройство не нужно:

```bash
./gradlew test
```

| Класс | Что проверяет |
|-------|---------------|
| `SearchQueryBuilderTest` | Подготовку поискового запроса: служебные символы FTS отбрасываются, пустой ввод отключает поиск, цифры считаются частью слова |
| `DiaryEntryTest` | Превью текста: схлопывание пробелов, обрезку по границе слова, текст без пробелов |
| `EntryFilterTest` | Активность фильтра, счётчик на кнопке, сброс с сохранением поиска и сортировки |

Самый важный из них — `SearchQueryBuilderTest`. Ошибка там означает не
«поиск нашёл не то», а падение SQL-запроса на обычном пользовательском
тексте вроде `код -ошибки`.

### Тесты на устройстве (19 тестов)

Требуют подключённого телефона или эмулятора — проверяют настоящий движок
SQLite:

```bash
./gradlew connectedAndroidTest
```

`EntryDaoTest` поднимает базу в памяти и проверяет полный CRUD, обе связи,
каскадное удаление, поиск (включая независимость от регистра в русском
тексте), совместную работу фильтров, сортировку и запросы статистики.

## 3. Ручное тестирование

Сценарии, которые нужно пройти на устройстве перед сдачей.

### Первый запуск

- [ ] Приложение устанавливается и запускается без ошибок
- [ ] Виден пустой дневник с кнопкой «Создать первую запись»
- [ ] Экран статистики показывает заглушку, а не пустые графики

### Создание записи

- [ ] Пустой заголовок подсвечивается красным с пояснением
- [ ] Заголовок длиннее 100 символов не принимается
- [ ] Без выбранного настроения запись не сохраняется
- [ ] Ошибка исчезает сразу при исправлении поля
- [ ] Будущие даты в календаре недоступны
- [ ] Новый тег создаётся и сразу отмечается
- [ ] После сохранения запись появляется в списке
- [ ] «Отмена» закрывает форму без сохранения

### Просмотр, изменение, удаление

- [ ] Нажатие на карточку открывает запись целиком
- [ ] Долгое нажатие помечает запись избранной, появляется звёздочка
- [ ] «Редактировать» открывает форму с заполненными полями
- [ ] После сохранения изменения видны и в списке, и на экране записи
- [ ] Появляется строка «Изменено …»
- [ ] «Удалить» показывает диалог подтверждения
- [ ] «Отмена» в диалоге оставляет запись на месте
- [ ] После удаления появляется сообщение с кнопкой «Отменить»
- [ ] «Отменить» возвращает запись вместе с тегами

### Поиск и фильтры

- [ ] Список фильтруется по мере ввода
- [ ] «парк», «Парк» и «ПАРК» дают одинаковый результат
- [ ] «парк» находит и «в парке», и «Парковка»
- [ ] Совпадения подсвечены в списке
- [ ] Ввод «код -ошибки» или незакрытой кавычки не роняет приложение
- [ ] Два слова сужают выборку, порядок слов не важен
- [ ] Чип настроения фильтрует список, повторное нажатие снимает фильтр
- [ ] Фильтры по категории и периоду работают вместе с поиском
- [ ] На кнопке фильтров видно их количество
- [ ] Все три режима сортировки меняют порядок
- [ ] При отсутствии совпадений видна заглушка «Ничего не найдено»
- [ ] Кнопка сброса очищает и поиск, и фильтры

### Статистика

- [ ] Числовые показатели совпадают с реальным числом записей
- [ ] Столбчатая диаграмма показывает семь дней, включая дни без записей
- [ ] Круговая диаграмма отражает распределение по категориям
- [ ] Серия дней не обнуляется утром, если есть вчерашняя запись
- [ ] После добавления записи статистика обновляется сама

### Настройки

- [ ] Все три темы переключаются мгновенно
- [ ] Выбранная тема сохраняется после перезапуска приложения
- [ ] Режим «Системная» следует ночному режиму телефона
- [ ] Смена формата даты сразу меняет вид карточек
- [ ] Выключение превью убирает текст из карточек
- [ ] Сортировка по умолчанию применяется при открытии вкладки «Дневник»

### Экспорт в PDF

- [ ] На пустом дневнике выводится сообщение, файл не создаётся
- [ ] Во время формирования виден индикатор, повторное нажатие не срабатывает
- [ ] Открывается системное окно «Поделиться»
- [ ] В документе есть все записи с датой, категорией, настроением и тегами
- [ ] Длинный текст переносится и не выходит за поля
- [ ] Записи не разрываются между страницами посередине

### Устойчивость

- [ ] Поворот экрана на форме не теряет введённый текст
- [ ] Поворот экрана на панели фильтров сохраняет выбор
- [ ] Свёртывание и разворачивание приложения не сбрасывает состояние
- [ ] Приложение не падает ни в одном сценарии выше

### Регрессии PDF и русского счётчика

`PdfAndCountRegressionTest` проверяет русские формы чисел при английской локали,
перенос длинного слова после обычного текста без потери Unicode и экспорт 1000
записей с текстом свыше 100 тысяч символов. Реальный PDF открывается через
Android PdfRenderer и должен занимать больше 130 страниц. Python-скрипт остаётся
приближённой проверкой алгоритма и не заменяет этот прогон на Android.
