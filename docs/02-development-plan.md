# План разработки приложения «Дневник» — 12 недель

Разработка разбита на 12 недельных этапов. **Каждый этап завершается
отдельным коммитом** в репозиторий с осмысленным названием — это одно из
требований ТЗ (раздел «Критерии оценки → GitHub»).

Формат названия коммита:

```
Неделя N: краткое описание выполненного этапа
```
