Дневник эмоций — приложение на Android для личных записей и отслеживания настроения. В нём можно сохранить мысли и события дня, выбрать эмоцию и категорию, а затем найти нужную запись через поиск и фильтры.

О приложении

Приложение подходит для людей, которые хотят вести дневник, сохранять воспоминания и замечать изменения своего настроения. Каждая запись может содержать заголовок, текст, дату, настроение и категорию.

Дневник эмоций помогает возвращаться к важным событиям и наблюдать за своим настроением с помощью статистики и графиков.

Основные функции
  - Добавление записей с заголовком, текстом, датой, настроением и категорией.
  - Редактирование и удаление записей.
  - Просмотр полного текста записи.
  - Поиск по заголовку или тексту.
  - Фильтрация по настроению, категории и периоду.
  - Сортировка по дате или заголовку.
  - Просмотр статистики и графиков.
  - Экспорт записей в PDF.
  - Создание и восстановление резервных копий.
  - Выбор темы оформления, формата даты и отображения текста в списке.
Экраны приложения
  - Главный экран — список записей с поиском, фильтрами и кнопкой добавления.
  - Экран добавления и редактирования — форма для заполнения записи, выбора даты, настроения и категории.
  - Экран записи — полная информация о событии и кнопки «Редактировать» и «Удалить».
  - Экран статистики — числовые показатели, график активности и распределение записей по категориям.
  - Экран настроек — выбор оформления, формата даты, экспорт PDF и работа с резервными копиями.
